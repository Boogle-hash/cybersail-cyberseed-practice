INCIDENT NOTE
-------------
A security analyst reported suspicious access to finance-related files.

Some events in the logs are red herrings:
- Failed logins do NOT prove an account was compromised.
- One external IP is an approved administrator VPN endpoint.
- The team has NOT confirmed data exfiltration.

INVESTIGATION PATH
------------------
Work through the evidence in this order:

1. In auth.log, find a SUCCESSFUL login from an EXTERNAL IP.
2. Check that IP in vpn_access.csv.
3. Check the account in employee_directory.txt.
4. Return to auth.log and see what happened immediately after that login.
5. Use the account STATUS to build the final flag.

FINAL FLAG FORMAT
-----------------
FLAG{<ACCOUNT_STATUS>_ACCOUNT_USED}

Example:
If the suspicious account's status were ACTIVE:
FLAG{ACTIVE_ACCOUNT_USED}

Use the actual status shown in employee_directory.txt.
