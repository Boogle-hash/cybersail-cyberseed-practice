# Cyber Sail Warm-Up #1: Incident Zero

Open `index.html` in a browser, or serve the folder with:

    python -m http.server 8000

Then browse to:

    http://localhost:8000

Designed for a 20-minute college-level cybersecurity club exercise.

Suggested timing:
- 1 minute intro
- 3–4 minutes easy
- 4–5 minutes medium
- 7–8 minutes hard
- 2–3 minutes debrief
