# Cyber Sail Warm-Up #1: Incident Zero

Publish this folder with GitHub Pages.

Designed for a 20-minute college-level cybersecurity club exercise.

Suggested timing:
- 1 minute intro
- 3–4 minutes easy
- 4–5 minutes medium
- 7–8 minutes hard
- 2–3 minutes debrief

Student-facing files:
- index.html
- evidence/auth.log
- evidence/employee_directory.txt
- evidence/vpn_access.csv
- evidence/incident_note.txt

Do NOT upload INSTRUCTOR_KEY.txt to the public student repository.

Update: Medium challenge now uses a two-step transformation. Hard challenge includes expanded logs and red herrings.
