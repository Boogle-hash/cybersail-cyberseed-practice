Cyber Sail Warm-Up #1: Incident Zero

Northstar Systems detected suspicious activity overnight. Recover all three flags before time expires.

20 minutes700 pointsTeam or Solo

Rules

You may use browser developer tools, CyberChef, Wireshark, PowerShell, terminal utilities, or any other non-destructive analysis tool.

Goal: explain what happened, not just guess a flag.

Easy — Hidden in Plain Sight 100 pts · target 3–4 min

A developer says the public status page was updated before the incident. Something was accidentally left behind.

Questions:

  1. What technique did you use to inspect the page?
  2. Using the flag format in the Incident Note, what final flag did you derive?

Medium — Layered Message 200 pts · target 4–5 min

An analyst recovered the value below. It has been transformed more than once. Your job is to follow the transformation chain.

TkVYVD1ST1QxMwpQQVlMT0FEPVNZTlR7UUJIT1lSX0dFTkFGU0JFWn0=

Questions:

  1. What encoding is used on the value shown above?
  2. After the first decode, what transformation does the message tell you to use next?
  3. Apply that transformation to the PAYLOAD. What final flag do you recover?

Hint 1 (-25 pts)

The outer value is a common encoding frequently recognized by CyberChef's Magic operation.

Hint 2 (-50 pts)

After the first decode, read the result literally — it tells you what transformation to use next.

Hard — Impossible Login 400 pts · target 7–10 min

Northstar Systems detected suspicious access to finance-related files. Your job is to identify the strongest evidence of unauthorized account use.

Authentication & File Access Log · Account Directory · VPN/IP List · Incident Note / Investigation Guide

Start with the Incident Note. It gives you the fastest investigation order.

Questions:

  1. Which account made the most concerning successful login?
  2. What source IP was used?
  3. According to the VPN/IP list, was that source approved?
  4. What status does the Account Directory show for that account?
  5. Which three files were accessed shortly after the successful login?
  6. Identify one event that looks suspicious but does not prove a successful compromise.
  7. What should IT do first with the suspicious account?
    • A. Leave it active and monitor it
    • B. Disable/revoke the account and reset its credentials
    • C. Delete the logs
    • D. Restart the server
  8. Using the FINAL FLAG FORMAT in the Incident Note, build the flag from the suspicious account name and its status.

Hint 1 (-25 pts)

Ignore failed logins at first. Focus on successful authentication from an external source.

Hint 2 (-50 pts)

There are two unapproved external IPs, but only one successfully authenticates.

Hint 3 (-75 pts)

The suspicious account is listed as DISABLED in the Account Directory.

Final Debrief

In one or two sentences, explain the incident using evidence from at least two different artifacts. State what the evidence supports and what it does not prove.
