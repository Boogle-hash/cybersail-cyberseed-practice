Cyber Sail Warm-Up #1: Incident Zero

Northstar Systems detected suspicious activity overnight. Recover all three flags before time expires.

20 minutes700 pointsTeam or Solo

Rules

You may use browser developer tools, CyberChef, Wireshark, PowerShell, terminal utilities, or any other non-destructive analysis tool.

Goal: explain what happened, not just guess a flag.

Easy — Hidden in Plain Sight 100 pts · target 3–4 min

A developer says the public status page was updated before the incident. Something was accidentally left behind.

Questions:

  1. What technique did you use to inspect the page?
  2. What flag did you recover?

Medium — Intercepted Message 200 pts · target 4–5 min

An analyst copied this value from an alert. Determine what it is and decode it.

Tm9ydGhzdGFyIGFsZXJ0OiB3b3Jrc3RhdGlvbj0xMC4yMC41LjQ3OyB1c2VyPW1yZWVkOyBGTEFHe0NIRUZfQ0FOX0NPT0t9

Questions:

  1. What encoding was used?
  2. Which workstation appears in the decoded message?
  3. What user is referenced?
  4. What flag did you recover?

Hint (-25 pts)

CyberChef's "Magic" operation may identify common encodings.

Hard — Impossible Login 400 pts · target 7–8 min

Northstar Systems detected suspicious access to finance-related files. Correlate the supplied evidence and determine what happened.

Authentication log · Account directory · VPN access list · Incident note

Questions:

  1. Which account is the strongest indicator of suspicious activity?
  2. What source IP authenticated with that account?
  3. What evidence shows the account should not have been active?
  4. What evidence shows the source was not approved?
  5. Which files were accessed?
  6. What should the first containment action be?
  7. What flag did you recover?

Hint 1 (-50 pts)

Start by comparing successful logins against the account directory.

Hint 2 (-75 pts)

Then compare the source IP against the approved VPN list.

Final Debrief

In one or two sentences, explain the incident using evidence from at least two different artifacts. State what the evidence supports and what it does not prove.
