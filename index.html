Cyber Sail Warm-Up #1: Incident Zero

Northstar Systems detected suspicious activity overnight. Recover all three flags before time expires.

20 minutes700 pointsTeam or Solo

Rules

You may use browser developer tools, CyberChef, Wireshark, PowerShell, terminal utilities, or any other non-destructive analysis tool.

Goal: explain what happened, not just guess a flag.

Easy — Hidden in Plain Sight 100 pts · target 3–4 min

A developer says the public status page was updated before the incident. Something was accidentally left behind.

Questions:

  1. What technique did you use to inspect the page?
  2. Using the flag format in the Incident Note, what final flag did you derive?

Medium — Layered Message 200 pts · target 4–5 min

An analyst recovered the value below from a suspicious note. It has been transformed more than once.

U1lOVHtRQkhPWVJfR0VOQUZTQkVafQ==

Questions:

  1. What was the first transformation you identified?
  2. What did the first result tell you about the second transformation?
  3. What is the final flag?

Hint 1 (-25 pts)

The outer layer is a very common text encoding.

Hint 2 (-50 pts)

After the first decode, the result should point you toward a letter-substitution transformation.

Hard — Impossible Login 400 pts · target 7–10 min

Northstar Systems detected suspicious access to finance-related files. Correlate the supplied evidence and determine what happened.

Authentication log · Account directory · VPN access list · Incident note

Recommended approach: Start with the authentication log, find a successful external login, verify the IP, then verify the account status.

Questions:

  1. Which account made the most concerning successful login?
  2. What source IP was used?
  3. Was that IP approved?
  4. What is the account's status?
  5. Which files were accessed immediately afterward?
  6. Name one suspicious-looking event that does not prove compromise.
  7. Using the format in the Incident Note, what final flag did you derive?

Hint 1 (-25 pts)

Ignore failed logins at first. Find a successful login from an external IP.

Hint 2 (-50 pts)

After you find that login, compare its IP against vpn_access.csv, then compare the account against employee_directory.txt.

Hint 3 (-75 pts)

The final flag uses the suspicious account's STATUS, not the username.

Final Debrief

In one or two sentences, explain the incident using evidence from at least two different artifacts. State what the evidence supports and what it does not prove.
